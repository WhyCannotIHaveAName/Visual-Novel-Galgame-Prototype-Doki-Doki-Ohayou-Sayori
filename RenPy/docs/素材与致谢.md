# 素材与致谢

## 原作

剧本与设计：尚睿洋（WhyCannotIHaveAName）。原 C 版调试协助：周飞扬，沿用原作署名。

来源：https://github.com/WhyCannotIHaveAName/Visual-Novel-Galgame-Prototype-Doki-Doki-Ohayou-Sayori ，基础提交 `c43b30a`。

本作品为非官方、非商业 DDLC 同人。DDLC 及其角色的相关权利归 Team Salvato；原作其他素材的权利归各自权利人。本次没有为原素材补写或推定一个新的授权。

四位女主以仓库图像作身份参考，本次重新绘制；旧素材保留在源码中。原背景仍保存在原型目录；修复版使用下列新绘制场景。原 `quiet.mp3` 不参与新版本播放，也不进入 Windows 包。台词中对 Your Reality 等歌曲的引用保留，游戏未附带这些商业录音。

## 本次新增美术

2.0 使用内置 ImageGen 生成 17 张独立场景和 2 张配角立绘；2.1 再生成 26 张女主立绘与 1 张黑日教室背景。没有通过网页抓取第三方画师作品。背景用秋日暖色、灰蓝夜色和清晰的前景留白统一视觉；场所是剧情用插画，不是对校园建筑与地理的精确复原。

Leo 与 Shane 以 C 版图片作外观参考，重新生成适合舞台叠加的立绘。女主以同一角色基准图逐张制作表情与道具变体，统一服装；舞台画布为 700×1080，按眼睛位置校准高度。

背景资产路径、提示词及生成文件编号见 [art-prompts.json](art-prompts.json)。两张配角图保留了复现描述及参考文件，未保留完整逐字请求，文件中已区分。项目实际引用的图片全部存放在 `game/images`，不依赖聊天缓存。

2.1 的逐字提示词、参考图及项目路径见 [art-prompts-2.1.json](art-prompts-2.1.json)。素材使用内置 ImageGen 生成，没有外部图片编辑或自动抠图步骤。

## 本次新增音乐

- `audio/ohayou.wav`：日常场景的明亮器乐循环，约 46 秒。
- `audio/blue_hour.wav`：安静、低速的晚间循环，约 58 秒。
- `audio/afterimage.wav`：隐藏线路的疏离音色循环，约 53 秒。

三段均为本次用程序编配和合成的旋律／和声，没有使用采样录音或商业曲目。生成程序保存在源码 `tools/compose_music.py`。它们是小型独立游戏的简洁伴奏，并非真人演奏。

## 引擎和字体

Ren’Py 8.4.1，Tom Rothamel 及贡献者。存读档、回退、历史、快进与回看采用引擎原生功能。标准界面由 SDK 模板补齐后进行修改。Windows 包包含运行库附带的许可文件。

中文字体为本机 Ren’Py SDK 配套的 `SourceHanSansLite.ttf`，同时与旧本地项目核对；未再次改造字形。Source Han Sans 基于 SIL Open Font License 1.1，原文附在 `licenses/SourceHanSans-OFL.txt`，来自 [Adobe 官方字体仓库](https://raw.githubusercontent.com/adobe-fonts/source-han-sans/release/LICENSE.txt)。西文与符号使用引擎随附 DejaVu Sans。

## 2.1 恐怖演出音效

`fx_signal.wav`、`fx_fracture.wav`、`fx_low.wav` 为本次程序合成，无第三方录音。首尾使用渐变包络避免点击杂音，服从音效音量、静音及恐怖演出等级。标准档包含细条错位、残像和异常立绘；减弱档取消移动条带及叠加眼部残片，并降低音效；关闭档不播放这些短演出和音效，剧情文本及隐藏章节背景仍保留。
