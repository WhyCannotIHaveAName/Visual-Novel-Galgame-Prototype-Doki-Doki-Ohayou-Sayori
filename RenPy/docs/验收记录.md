## 美术与呈现

逐张查看了新增背景和两张配角立绘，并检查真实游戏截图：中文字体、对话框、标题、多人站位、明信片／手册、存档和设置。Leo 与 Shane 的透明立绘已实际叠加到背景中。四位女主共 26 张透明立绘已重绘，统一每位人物的服装与画布，并在真实游戏中核对四人、双人和单人站位。

新增场景为艺术化插画，不是实际校园建筑的测绘。游戏没有配音。三段背景配乐为程序合成的器乐循环。

## 可复现检查

在 PowerShell 中运行源码目录的 `tools/verify.ps1 -Sdk <你的 RenPy SDK 文件夹>`。结果保存在 `qa-results/运行时间`，包含脚本检查、12 条运行路径、跨进程解锁、UI 截图。测试器先复制一份项目，排除已有存档与缓存；测试存档也在副本内，因为 Ren’Py 同时会写用户存档目录和项目的 `game/saves`。

测试器同时检查进程输出与新产生的异常文件，不能仅凭退出码认定通过。因为原生 Ren’Py 测试执行过程中某些异常可以被忽略，单独看「退出码 0」不足以验收。

发布包的 QA 文件和测试存档均被排除。原 C 版及 Ren’Py-MVP 与基础提交相比没有文件变更。

2.1 原始证据见 `verification/native-routes-2.1.txt`、`verification/lint-2.1.txt`、`verification/update21.txt`。旧版记录仍保留并带有旧版内部版本标识；发布后的包校验结果另存为 `verification/package-audit-2.1.json`。
