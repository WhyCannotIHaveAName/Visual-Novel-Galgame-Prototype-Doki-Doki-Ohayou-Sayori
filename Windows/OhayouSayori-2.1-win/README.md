# Doki Doki Ohayou Sayori · 完整修复版 2.1

这是基于原作者现有剧本完成的 Ren’Py 版：九个结局、五篇小剧场和 39 项成就均可正常完成。保留校园日常、人物关系和原有分支，补齐演出与界面，修复流程错误。

## 玩游戏

Windows 成品包解压后，双击 `OhayouSayori.exe`，不需要安装 Python 或 Ren’Py。请保留同目录的 `game`、`lib`、`renpy` 文件夹。不要在压缩包里直接运行。

这是源码目录；若从源码运行，用 Ren’Py 8.4.1 打开本目录，再点击「启动项目」。

- 左键／回车：推进与确认。空格推进对话，选择时请点击选项。
- 滚轮向上／Page Up：回退。Ctrl：按住快进已读文字。
- 右键／Esc：打开存读档和设置。H：暂时隐藏对话框。
- 主菜单「回忆手册」：查看结局、已读章节、成就、小剧场和美术手帐。
- 选项较多时，可以滚动选项区域；隐藏线路保留了原作的乱码选项。
- 回看使用独立路线状态，结束后回到手册；回看也能收集成就。需要中途保存的长篇阅读，请从主线进入。

游戏含抑郁、自伤／自杀相关叙述、死亡、关系冲突与打破第四面墙的情节。开场会明确提示；设置中可将恐怖演出设为标准、减弱或关闭。没有新增血腥画面。

2.1 沿用 2.0 的存档目录 `OhayouSayori-Restored-2`，保留已有收集记录；未整理原型的存档不接管。解锁和阅读设置会在退出后保留。测试进度没有包含在发布包中。

## 2.1 新增

- 主菜单或 Esc 菜单进入「调试室」：99 个剧情入口与 4 组恐怖演出预览，可搜索章节号、角色或开场台词。无需解锁。
- 可设隐藏线计数 0/1/2、强制 Sayori 隐藏判定；开启 F6 快捷入口后，可在剧情中直接打开。
- 调试采用独立回看，不登记成就、不更新已读章节；点击「结束本次测试」返回原位置。普通回忆手册的收集规则不变。
- 立绘检查支持六名人物、所有表情、1/2/4 人布局以及深浅底色。
- 六处隐藏选项带来异常信号；Monika 章节增加黑日教室、错位残像、异常凝视和假 END，配有三段原创合成音效。

## 给原作者的评价

我最喜欢的不是「像 DDLC」这一点，而是它有非常具体的大学生活：工程报告里的争执、全英文课程、闵行到市区的出游、食堂与渡口，还有老朋友电话里那些不太直说的话。这些细节使主角的孤独有了具体的场所和关系。「三个烤红薯」和反复出现的拥抱也形成了自己的记忆点。

我觉得最值得继续打磨的是后段大段自我分析的节奏：有些观点由人物反复解释，场景里的行动暂时停住了。本次先保留你的表达，用场景、配乐和段落间的演出承接，没有替你把故事改成另一篇作品。以后如果重写，优先考虑让一次行动或一次失败承担一部分解释。

程序上，你已经做出过外置文本、分支、存档与解锁，这不是「什么也不懂所以什么也没做成」。真正拖累进度的是同一份长剧本同时承担了剧情、系统和美术调度，机械维护自然越来越多。因此这次把它们拆开；以后写对白不需要动存档系统。

本次把精力集中在完成 Ren’Py 游戏。C 版作为你的第一版叙事引擎保留，没有另做一套重复的图形界面。
