# Windows 可玩版 2.1

已解压的完整游戏位于 [OhayouSayori-2.1-win](OhayouSayori-2.1-win/)。

下载整个仓库（GitHub 绿色 Code → Download ZIP）并完整解压，或使用 Git 克隆，然后进入该文件夹，双击 `OhayouSayori.exe`。不需要安装 Python 或 Ren’Py。请保留旁边的 `game`、`lib`、`renpy` 等目录；只下载 exe 无法运行。

主菜单「调试室」可直接测试章节、查看立绘比例和预览恐怖演出。可在调试室开启 F6 快捷键；阅读设置提供标准、减弱、关闭三档恐怖演出。

本目录包含运行库与许可文件，不含个人存档和测试进度。2.1 沿用 2.0 的存档目录。源码与继续创作说明见 [RenPy](../RenPy/README.md)。
